# Privacy Policy — LAB-013 Grocery & Meal Planner

**Effective date:** 6 September 2026

## 1. Scope

This policy applies to the private household application **Richard Nguyen LAB-013 Grocery & Meal Planner**.

The application supports personal recipe organisation, meal planning, kitchen inventory awareness and grocery-list preparation.

## 2. Pinterest data accessed

Where the account owner authorises Pinterest access, the application may read only the data necessary for the household recipe workflow, such as:

- the authorised account's boards;
- board sections;
- Pins and Pin identifiers;
- Pin titles, descriptions and source/destination links where available;
- publicly or API-provided Pin images or image references; and
- source metadata needed to maintain recipe provenance and prevent duplicate ingestion.

The current pilot does not use Pinterest access to create, edit, delete, schedule or publish Pins.

## 3. Purpose of use

Pinterest-derived data is used only to:

- build and maintain a private household recipe library;
- allow household members to select recipes for meal planning;
- identify ingredients required by selected recipes;
- compare those requirements with household kitchen inventory; and
- prepare grocery requirements for later household review.

Pinterest-derived data is not used for advertising, audience profiling, resale, lead generation or unrelated commercial purposes.

## 4. Data minimisation and storage

The application is designed to retain only the minimum information required for the household workflow.

Pinterest account credentials and passwords are not stored by the application. Access tokens, where required by the authorised API connection, must be handled through the applicable secure authentication mechanism and must not be placed in public application content.

## 5. Sharing and sale

Pinterest-derived personal data is not sold.

Data is not intentionally disclosed to advertisers or data brokers. Household planning records may be shared only with authorised household participants for the purpose of jointly managing recipes, meals, inventory and grocery requirements.

## 6. Retention and deletion

Pinterest-derived source records are retained only while required for the household recipe library or its audit/history needs.

The account owner may request that imported Pinterest source records be disconnected or deleted from the household application. Revoking Pinterest authorisation prevents future API access; retained application records can then be removed in accordance with the household application's retention controls.

## 7. Security

The application uses least-privilege, read-only Pinterest access during the current pilot and separates source metadata from sensitive account credentials.

No autonomous purchasing, financial transaction or Pinterest publishing authority is created by Pinterest access.

## 8. Children

The application is a private household planning tool and is not directed to children as an independent online service.

## 9. Changes to this policy

This policy may be updated if the application's data sources, permissions or operating model materially change. The current published version will state its effective date.

## 10. Contact

Application owner: **Richard Nguyen**

For privacy or data-removal requests, contact the application owner through the GitHub account associated with this repository.
