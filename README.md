# Richard Nguyen LAB-013 Grocery & Meal Planner

Private household meal-planning and grocery-optimisation application.

## Purpose

LAB-013 uses read-only access to the account owner's saved boards and Pins to support:

- a private visual recipe library;
- weekly meal planning;
- household fridge and pantry awareness;
- missing-ingredient identification;
- grocery-list generation;
- nutrition and health comparison; and
- later, separately governed grocery optimisation.

## Pinterest use

Pinterest access is read-only for the current pilot. The application is intended to read the account owner's boards, board sections and Pins for personal household meal planning.

The current pilot does **not** create, edit, delete, schedule or publish Pinterest content.

## Data handling

Only the minimum source metadata required for the household recipe and meal-planning workflow is retained. The application is not an advertising product and does not sell Pinterest-derived data.
